LossPacket Brand Kit v1 — Paper and Ink / Joined LP

START HERE
Open index.html for the interactive specimen. All fonts, image assets, SVGs and scene data are local. No build step or external runtime libraries are required. A static HTTP server offers the most reliable browser preview; direct file opening also works because scene data is embedded in brand-kit-data.js.

USAGE
The kit is a brand artifact, not a live claim service. Sample controls do not send, file, collect payment, connect financial systems or submit user details. All scenario material is synthetic. Final social profile URLs are not established; footer icons are specimens.
Logo masters are path-based SVGs; no font installation is required to display them. The symbol uses bespoke Bezier paths redrawn from the selected Joined LP reference. The wordmark uses Source Serif 4 outlines. All symbol and favicon exports preserve the same master geometry.

LICENSES
Original LossPacket marks, pictograms, textures and generated scenes are project deliverables. Third-party font/icon licenses are bundled separately. Brand trademark rules for LinkedIn and Crunchbase remain applicable; geometry is not altered. Brand/logo clearance is not performed by this package.
